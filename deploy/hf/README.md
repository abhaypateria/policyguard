# PolicyGuard

Temporally-grounded, self-correcting RAG assistant for banking compliance: answers only from the
indexed policies, cites file + page + version, refuses when evidence is weak, flags conflicts between
internal policy and RBI rules, and seals every answer into a hash-chained audit log.

Source and documentation: https://github.com/abhaypateria/policyguard
